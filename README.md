# Poonam Jewellers — Official Website

A luxury, modern web application for **Poonam Jewellers** (Dombivli East), crafted with Next.js, React 19, TypeScript, and Tailwind CSS.

---

## ✨ Features

- **Luxury Brand Aesthetics**: Custom typography (Playfair Display & DM Sans), warm gold palette, and smooth micro-interactions.
- **Modern Split Hero Layout**: Clean high-contrast brand narrative paired with master craftsmanship showcase.
- **Inside the Atelier Reel**: Native Instagram Reel video integration with playback and sound controls.
- **Interactive Master Vault**: Curated Gold, Diamond, Silver, and Platinum collections with direct WhatsApp inquiry.
- **Curated Occasions**: Uniform luxury editorial cards for Bridal Edit, Everyday Luxury, and Festive Glow.
- **Showroom Consultation Modal**: Interactive booking form pre-filling bespoke WhatsApp consultation requests.
- **Compact Unified Luxury Footer**: Clean 3-column footer with contact details, store directions, and embedded Google Maps showroom locator.
- **Zero Watermarks & Self-Contained**: 100% production ready with local brand logo assets and optimized metadata.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5
- **UI & Icons**: React 19, Lucide React
- **Styling**: Tailwind CSS & CSS Design System
- **Package Manager**: pnpm

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
pnpm install
```

### 2. Run Local Development Server
```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
pnpm build
```

### 4. Start Production Server
```bash
pnpm start
```
